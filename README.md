# J.A.R.V.I.S. — Sistema de Automação por Voz Total do Windows (Hands-Free)

O **J.A.R.V.I.S.** foi transformado em um piloto operacional do seu computador: uma ferramenta focada em **executar ações reais no Windows 100% por voz**, sem necessidade de tocar no mouse ou no teclado.

---

## ⚡ Inicialização Automática ao Ligar o PC

Para que o Jarvis inicie automaticamente sozinho toda vez que você ligar o computador:
1. Dê um duplo clique no arquivo:
   ```cmd
   install_autostart.bat
   ```
2. Pronto! O Jarvis será iniciado silenciosamente na inicialização do Windows e abrirá o painel no navegador pronto para ouvir sua voz.
*(Se algum dia quiser desativar, basta clicar em `uninstall_autostart.bat`)*.

---

## 🎙️ Guia Completo de Comandos de Voz Operacionais

Basta falar naturalmente no microfone:

### 🌐 Navegação na Web & Sites
- *"Jarvis, abrir o YouTube"* (Abre o YouTube imediatamente no Chrome/Edge)
- *"Jarvis, abrir o Google"*
- *"Jarvis, abrir o WhatsApp"*
- *"Jarvis, abrir Netflix"*
- *"Jarvis, abrir ChatGPT"*
- *"Jarvis, tocar [música ou vídeo] no YouTube"* (ex: *"Jarvis, tocar Queen no YouTube"*)
- *"Jarvis, pesquisar no Google por [termo]"*

### 🪟 Controle de Janelas e Navegador (Sem Mouse)
- *"Jarvis, fechar janela"* (Fecha o programa ou janela ativa - Alt + F4)
- *"Jarvis, alternar janela"* (Troca para a próxima janela aberta - Alt + Tab)
- *"Jarvis, maximizar"* (Coloca a janela em tela cheia)
- *"Jarvis, minimizar"* (Minimiza a janela atual)
- *"Jarvis, mostrar área de trabalho"* (Minimiza tudo de uma vez)
- *"Jarvis, rolar para baixo"* (Rola a página do navegador para ler)
- *"Jarvis, rolar para cima"*
- *"Jarvis, nova guia"* (Abre uma aba nova no navegador - Ctrl + T)
- *"Jarvis, fechar guia"* (Fecha a aba atual - Ctrl + W)
- *"Jarvis, atualizar página"* (F5)

### 📁 Abertura de Pastas e Programas do PC
- *"Jarvis, abrir Downloads"*
- *"Jarvis, abrir Documentos"*
- *"Jarvis, abrir Imagens"*
- *"Jarvis, abrir Área de Trabalho"*
- *"Jarvis, abrir Disco C"*
- *"Jarvis, abrir Calculadora"*
- *"Jarvis, abrir Bloco de Notas"*
- *"Jarvis, abrir Gerenciador de Tarefas"*
- *"Jarvis, abrir Configurações"*
- *"Jarvis, abrir Paint"*

### 🔊 Volume e Mídia
- *"Jarvis, aumentar volume"* ou *"Mais alto"*
- *"Jarvis, diminuir volume"* ou *"Abaixa o som"*
- *"Jarvis, mutar"* / *"Desmutar"*
- *"Jarvis, pausar"* / *"Play"*
- *"Jarvis, próxima música"* / *"Voltar música"*

### 🔒 Segurança e Ferramentas
- *"Jarvis, tirar print"* (Salva captura de tela em `/screenshots`)
- *"Jarvis, bloquear PC"* (Trava a sessão do Windows)
- *"Jarvis, limpar lixeira"* (Esvazia a lixeira do Windows)
- *"Jarvis, status do sistema"* (Uso de CPU e RAM atual)
